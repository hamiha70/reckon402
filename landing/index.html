The Problem

AI agents can already pay for services autonomously using x402. But every payment starts from zero — there's no memory, no trust, no history. Reckon402 changes this.

How It Works

01

Pay

Buyer agent resolves merchant ENS name, receives x402 payment request, signs EIP-3009 authorization. No wallet popup. No human in the loop.

02

Settle

Reckon402 Facilitator validates authorization, submits on-chain settlement, distributes funds via Splitter, confirms in D1.

03

Earn Trust

Facilitator writes ERC-8004 attestation proving delivery. Reputation grows. Gateway adjusts price on next resolution.
